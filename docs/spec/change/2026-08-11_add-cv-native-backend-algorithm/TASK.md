## 剩余风险

- GrabCut 不是语义分割，复杂背景、前景背景近色和主观主体场景仍可能回退或产生不理想 Mask。
- Python/OpenCV 线程在请求超时后不能被强制终止；工作图、并发和 OpenCV 线程上限用于控制影响。
- 本次只验证了受控图片和功能并发边界，没有进行生产负载压测或大规模真实图片质量评测。
- 前端尚未引入 Testing Library/jsdom 组件测试环境；模式布局、通知计时和手动关闭由真实
  Chrome/CDP 联调验证，后续可将这些场景沉淀为持续集成中的组件或端到端测试。
- 浏览器联调使用本地 Chrome/CDP 驱动，不是持续集成中的端到端测试；后续交互变更仍需同步
  回归上传、参数修改、Generate、等待锁定和 Download 状态。
