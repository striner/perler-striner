# 轻量终端 AI 对象选择与插画像素化实施计划

## 计划状态

- 状态：执行中
- 前置条件：2026-08-18 修订的 `SPEC.md` 已由用户确认执行

## 阶段 1：两阶段契约与模型工件

- 做什么：定义对象分析契约、归一化 bbox、候选实例结构和签名 token；将 Tiny Model 工件切换为 YOLOE-26M Prompt-free、SAM2.1-S 和后续 Cartoonizer。
- 回应目标：上传后立即得到可解释对象清单，模型不入 Git，完整运行工件控制在 200 MiB 内。
- 怎么实现：新增分析输入/输出数据类和 `/api/v1/analyze`；token 使用版本化 JSON、图片 SHA-256、候选列表、过期时间和 HMAC-SHA256；更新 `ModelStore`、prefetch、环境变量和下载文档。
- 结果：前后端可在不缓存图片的情况下完成 analyze/process 两阶段关联，模型缺失或校验失败时能力接口明确不可用。

## 阶段 2：对象分析服务

- 做什么：用 YOLOE-26M Prompt-free 分析原图并输出候选实体。
- 回应目标：对象类型、bbox、置信度、YOLOE 原始英文标签显示、最多 24 个候选。
- 怎么实现：按后端归一化方向后的图像运行 640 输入推理；读取 bbox、class、confidence 和粗 Mask；过滤无效面积、低置信度和抽象标签，执行重叠去重与显著性排序；直接使用 YOLOE 原始英文类别并给同类型实例稳定编号。
- 结果：`/api/v1/analyze` 返回可直接叠加的稳定候选列表和签名 token。

## 阶段 3：选中实例精细分割与成品流水线

- 做什么：生成请求验证分析 token，以选中 bbox 驱动 SAM2.1-S，随后执行构图、风格化、边缘、限色和像素化。
- 回应目标：只保留用户选中的具体实例，不重新猜测语义，不持久化分析状态。
- 怎么实现：校验图片摘要、token 版本、算法版本、过期时间和实例 ID；把 bbox 从分析坐标映射到工作图；逐实例分割、修复、去重后做并集。复用现有 framing、边缘、量化、pixelize 和输出校验，在其间增加可替换 Cartoonizer 接口。
- 结果：相同图片和选择产生稳定 RGBA；错误 token、空选择和空 Mask 返回标准错误并触发前端回退。

## 阶段 4：前端对象选择体验

- 做什么：Tiny Model 上传后自动分析，在图片上叠加 bbox，并提供实例复选列表。
- 回应目标：用户能够看见、理解并选择后端识别对象，然后手动触发后续生成。
- 怎么实现：扩展处理客户端的 analyze 响应校验；增加 `empty/analyzing/selection_ready/generating/ready` 状态；新图和切换模式触发可取消分析。原图容器使用稳定宽高比和绝对定位 bbox；点击 bbox/复选框同步选择，默认选择显著性最高对象。选择和生成参数变化只使成品失效，不重复分析。
- 结果：Tiny Model 不再显示 Prompt；至少选中一个实例才能 Generate；等待期间控件锁定，成功后 Download。

## 阶段 5：风格化与验证

- 做什么：接入 Cartoonizer 接口和评估权重，完成真实图片、回退、并发和前端交互验证。
- 回应目标：逼近参考图的扁平插画效果，同时维持 Alpha、限色和固定分辨率契约。
- 怎么实现：先以边缘感知基线打通完整链路，再比较 AnimeGANv2 PyTorch `celeba_distill`、`face_paint_512_v2`、`paprika` 和权重插值结果。当前采用最接近扁平参考风格的 `celeba_distill`，最长边限制为 768px，模型只改变 Mask 内 RGB，Alpha 仍由 SAM 决定。使用 `007-src.jpg` 完成 CPU 真实接口和 Chrome 集成测试，比较微边缘密度、区域碎片、主体结构、色彩偏移和人工观感；随后运行后端单元/接口测试、Ruff、前端 Vitest、Astro check/build 和真实 Chrome 点击测试。
- 结果：两阶段链路、AnimeGAN 风格化和浏览器回退均可运行；`celeba_distill` 的扁平度明显改善，但仍可能改变嘴部、眼镜和身份特征，尚不等同于目标参考图。最终生产权重与许可、扩展样本风格验收及 CUDA 指标继续明确记录为待完成。

## 当前执行与验证结果

- `007-src.jpg` 的分析接口返回 10 个候选对象，API 与前端均使用 YOLOE 原始英文标签；前端可按实例选择并提交生成。
- CPU 环境已完成真实 analyze/process 调用，Chrome 桌面和移动视口已验证分析、选择、生成、下载与后端失败回退。
- `celeba_distill` 已进入完整流水线；`face_paint_512_v2` 身份保持较好但偏绘画，`paprika` 色彩偏移过强，权重插值未形成更优折中，后三者不进入当前运行链路。
- 当前验证不覆盖生产授权结论、目标 NVIDIA CUDA 性能指标及完整的多人、动物、边缘主体、重叠对象和无候选样本矩阵。
